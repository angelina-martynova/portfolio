# 03 — Running Cumulative Metrics

### Goal
Track cumulative performance metrics over time to understand long-term trends in user and order value.

### Metrics
- `running_arpu` — cumulative revenue per all users
- `running_arppu` — cumulative revenue per paying users
- `running_aov` — cumulative revenue per all orders

### Insights
- Running ARPU and ARPPU show gradual increase over time
- Running AOV remains relatively stable
- Metrics indicate growing user engagement and order frequency

### Visualizations
- Cumulative ARPU, ARPPU, and AOV trends
- Long-term performance trajectory

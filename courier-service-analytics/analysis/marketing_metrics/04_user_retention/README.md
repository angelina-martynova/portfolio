# 04 — User Retention

### Goal
Calculate daily retention rate for all users grouped by cohorts based on first interaction date.

### Metrics
- `retention` — daily retention rate as percentage
- `start_date` — user's first interaction date
- `day_number` — days since first interaction
- `start_month` — month of first interaction
- `cohort_size` — number of users in each cohort

### Insights
- Retention rates vary significantly across different cohorts
- Typical retention pattern shows highest drop after first day
- Long-term retention remains stable for engaged users
- Seasonal patterns may affect retention rates
